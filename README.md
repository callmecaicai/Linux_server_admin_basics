# Linux 服务器系统管理 · 用户 / 权限 / 目录 / 磁盘 · 知识库

> 一套把 **用户 / 权限 / 目录架构 / 多用户共享 / 多盘管理** 统一到同一套原理的笔记，面向"在一台多人共享的服务器上安全干活"的人，也面向 **AI agent**——结构确定、可检索、可直接据此操作与排查。

---

## 这是什么

一台多用户、多块盘的 Linux 服务器，好几个人一起用。本合集回答：**多个人怎么共享而不互相踩踏？磁盘怎么规划分工？谁能动谁的东西（权限）？整台机器的目录按什么逻辑摆？**

> 全库示例中的用户名 / 路径 / 主机名（`alice`、`/data`、`gpu-server` 等）**均为占位，非任何真实环境**。

---

## 一致性脊柱

**一根主轴**：服务器管理 = 管**人** + 管**地** + 管**人对地的权利**。三者全交汇在 `ls -l` 的一行里：

```
-rw-r--r--  1  alice  alice  4096  model.pt
└─权利rwx─┘     └人┘   └组┘         └─地(文件)─┘
```

**三个追问**（看任何权限问题都问这三句）：
1. **谁**？（哪个 user / 属于哪个 group）
2. **什么权利**？（rwx 的哪几位、对 owner/group/other 哪一档）
3. **在哪块地**？（哪个目录 / 哪块盘，是系统地盘还是数据地盘）

## 怎么用

- **系统学**：按 `00 → 05` 顺序读，每章结尾"✅ 自检"答得出再往下。
- **查操作**：每章有命令表与"🧠 速记卡"，是该主题可直接照抄的压缩结论。

### 给 AI agent 的使用提示
- 每章"🧠 速记卡"= 可直接引用的压缩结论；正文 = 展开依据。
- 命令均标注了**是否需要 root**与**风险**；在多用户机上操作前，先按"三个追问"定位。
- ⚠️ 写操作（chmod/chown/mkfs 等）在共享机上务必先确认无人占用再执行。
